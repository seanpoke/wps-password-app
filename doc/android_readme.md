## 1. 项目概述

### 1.1 项目背景

在日常办公中，用户经常需要处理大量的WPS文档，其中许多文档都设置了密码保护。每次打开这些文档时，用户都需要手动输入密码，这不仅繁琐，而且容易忘记密码。为了解决这一问题，我们开发了WPS密码自动填充插件，旨在为用户提供便捷的密码管理和自动填充功能。

随着移动办公的普及，越来越多的用户在Android设备上使用WPS Office应用。为了让这些用户也能享受到密码自动填充的便捷，我们需要将现有的Windows平台插件迁移到Android平台，并利用Android的无障碍模式实现类似的功能。

### 1.2 项目目标

- 自动检测WPS文档的密码加密窗口
- 提供密码生成功能，创建安全的随机密码
- 自动填充密码到解密窗口
- 自动保存密码到安全存储
- 提供用户友好的界面和操作体验
- 确保无障碍功能符合WCAG 2.1 AA级标准

### 1.3 主要功能特点

- **密码生成**：生成符合安全标准的随机密码
- **自动填充**：自动检测并填充密码到WPS解密窗口
- **密码管理**：自动保存密码到安全存储
- **悬浮按钮**：在密码加密窗口显示便捷操作按钮
- **通知栏图标**：提供通知栏图标和快捷操作
- **登录验证**：支持用户登录验证
- **实时监控**：实时监控WPS进程和窗口
- **无障碍支持**：符合WCAG 2.1 AA级无障碍标准

### 1.4 适用范围

本插件适用于Android操作系统上的WPS Office应用，支持以下文件格式：

- .docx, .doc
- .xlsx, .xls
- .pptx, .ppt

#### 1.5.1 无障碍设计目标

## 3. 技术实现细节

### 3.1 系统整体架构设计

项目采用模块化设计，主要包含以下核心模块：

1. **监控模块（Monitor）**：负责监控WPS进程和窗口，定位密码对话框和输入框
2. **业务模块（Business）**：包含密码生成和安全存储功能
3. **输入模拟模块（Simulator）**：负责模拟键盘输入和触摸操作
4. **UI模块**：提供通知栏、悬浮按钮和登录界面
5. **工具模块（Utils）**：提供日志记录和全局状态管理

### 3.2 技术栈选型

| ---- | -------------------- | ------- | ------------- | ------------------ |

### 3.3 核心功能模块说明

#### 3.3.1 监控模块（Monitor）

**功能描述**：监控WPS进程和窗口，定位密码对话框和输入框，获取窗口信息。

**职责划分**：

- 检测WPS进程是否运行
- 查找密码加密和解密对话框
- 定位密码输入框和确认密码输入框
- 查找应用按钮
- 获取窗口文本和位置信息
- 解析文档路径

**核心实现逻辑**：

- 使用AccessibilityService监听WPS应用的窗口变化
- 处理AccessibilityEvent事件，识别密码相关窗口
- 使用AccessibilityNodeInfo遍历视图层次结构，定位输入控件
- 使用多种方法尝试定位窗口，提高成功率

**关键类**：`WpsMonitorService`

**无障碍标准符合性**：

- 符合WCAG 2.1 AA级标准的2.1.1 键盘和2.4.3 焦点顺序条款，确保所有功能都可以通过键盘操作，且焦点顺序逻辑合理

#### 3.3.2 业务模块（Business）

**功能描述**：包含密码生成和安全存储功能。

**职责划分**：

- 生成安全的随机密码
- 读取和写入密码到安全存储
- 管理文档UID
- 处理外部密码存储

**核心实现逻辑**：

- 密码生成：使用随机算法生成包含大小写字母、数字和特殊字符的密码
- 安全存储：使用Android KeyStore系统存储密码
- UID管理：为每个文档生成唯一标识符，用于追踪和管理

**关键类**：`PasswordGenerator`, `PasswordStorage`

**无障碍标准符合性**：

- 符合WCAG 2.1 AA级标准的3.3.2 标签或指令条款，为用户提供清晰的密码生成和存储操作指令

#### 3.3.3 输入模拟模块（Simulator）

**功能描述**：模拟键盘输入和触摸操作，实现密码填充和快捷键操作。

**职责划分**：

- 模拟密码输入到输入框
- 模拟键盘快捷键
- 模拟触摸点击操作
- 清空输入框内容

**核心实现逻辑**：

- 使用AccessibilityNodeInfo的performAction方法模拟输入和点击
- 使用InputMethodManager处理输入法相关操作
- 处理不同窗口类型的输入方式

**关键类**：`InputSimulator`

**无障碍标准符合性**：

- 符合WCAG 2.1 AA级标准的2.5.1 指针手势条款，确保所有功能都可以通过单一指针操作完成

#### 3.3.4 UI模块

**功能描述**：提供用户界面，包括通知栏、悬浮按钮和登录界面。

**职责划分**：

- 通知栏图标和快捷操作
- 悬浮按钮（生成密码和提取密码）
- 登录界面
- 通知窗口

**核心实现逻辑**：

- 使用Android SDK创建界面
- 响应按钮点击事件
- 显示通知栏提示
- 处理用户登录验证

**关键类**：`NotificationManager`, `FloatingButton`, `LoginActivity`, `NotificationActivity`

**无障碍标准符合性**：

- 符合WCAG 2.1 AA级标准的1.4.3 对比度和2.4.6 标题和标签条款，确保界面元素具有足够的对比度，且所有控件都有清晰的标题和标签

#### 3.3.5 工具模块（Utils）

**功能描述**：提供日志记录和全局状态管理功能。

**职责划分**：

- 记录日志信息
- 管理全局状态（登录信息、服务器地址等）

**核心实现逻辑**：

- 使用单例模式管理全局状态
- 提供不同级别的日志记录
- 确保线程安全

**关键类**：`Logger`, `GlobalState`

**无障碍标准符合性**：

- 符合WCAG 2.1 AA级标准的4.1.2 名称、角色、值条款，确保用户界面组件的名称、角色和值可以通过编程方式确定

### 3.4 数据模型设计

#### 3.4.1 存储方式

项目使用以下存储方式：

1. **Android KeyStore**：用于安全存储文档密码
2. **Room数据库**：用于存储文档路径和对应的UID
3. **SharedPreferences**：用于存储应用配置和登录信息

#### 3.4.2 核心数据对象

| 数据对象 | 类型     | 描述                 | 存储方式              |
| ---- | ------ | ------------------ | ----------------- |
| 文档路径 | String | 文档的完整路径            | Room数据库           |
| 密码   | String | 文档的加密密码            | Android KeyStore  |
| UID  | String | 文档的唯一标识符           | Room数据库           |
| 登录信息 | 复杂对象   | 包含用户名、token、服务器地址等 | SharedPreferences |

#### 3.4.3 数据流转说明

1. **密码生成流程**：
   - 用户点击悬浮按钮的"生成密码"按钮
   - `PasswordGenerator`生成随机密码
   - `InputSimulator`将密码填充到输入框安全存储
   - 监控应用按钮点击事件
   - 文档关闭后，将密码写入安全存储
2. **自动填充流程**：
   - 监控到解密窗口
   - 从安全存储中读取密码
   - `InputSimulator`将密码填充到输入框并模拟确认
3. **登录流程**：
   - 用户输入登录信息
   - 发送登录请求到服务器
   - 存储token和用户信息到SharedPreferences

### 3.5 关键业务流程说明

#### 3.5.1 密码生成和填充流程

1. **触发条件**：用户打开WPS文档的密码加密窗口
2. **流程步骤**：
   - 监控模块检测到密码加密窗口
   - 显示悬浮按钮
   - 用户点击"生成密码"按钮
   - 密码生成器生成随机密码
   - 输入模拟器将密码填充到输入框
   - 监控应用按钮点击事件
   - 文档关闭后，将密码写入安全存储

#### 3.5.2 自动填充流程

1. **触发条件**：用户打开加密的WPS文档
2. **流程步骤**：
   - 监控模块检测到密码解密窗口
   - 从安全存储中读取密码
   - 输入模拟器将密码填充到输入框
   - 模拟点击确认按钮

#### 3.5.3 文档关闭后密码写入流程

1. **触发条件**：用户关闭加密的WPS文档
2. **流程步骤**：
   - 监控服务检测到文档关闭
   - 从缓存中获取密码
   - 将密码写入安全存储
   - 保存文档UID到数据库

#### 3.5.4 登录流程

1. **触发条件**：首次运行插件或登录状态失效
2. **流程步骤**：
   - 显示登录界面
   - 用户输入登录信息
   - 发送登录请求到服务器
   - 存储token和用户信息到SharedPreferences

#### 3.5.5 监控WPS进程流程

1. **触发条件**：插件启动
2. **流程步骤**：
   - 启动AccessibilityService
   - 监听WPS应用的窗口变化
   - 检测密码相关窗口
   - 处理窗口事件

## 4. 开发指南

### 4.1 环境要求

- Android 5.0（API 21）或更高版本
- Android Studio 2022或更高版本
- Kotlin 1.8.0或更高版本
- WPS Office for Android 11.0或更高版本

### 4.2 依赖安装

1. 克隆项目代码到本地
2. 打开Android Studio，加载项目文件 `WpsPasswordManagerAndroid`
3. 项目会自动安装以下依赖：
   - Retrofit 2.9.0
   - Room 2.4.3
   - AndroidX Core
   - AndroidX AppCompat
   - AndroidX ConstraintLayout

### 4.3 配置文件设置

项目的主要配置文件包括：

1. **AndroidManifest.xml**：声明权限和服务
   - 声明辅助功能服务
   - 声明前台服务权限
   - 声明悬浮窗权限
   - 声明网络权限
2. **build.gradle**：配置依赖和构建选项
3. **res/values/strings.xml**：存储字符串资源
4. **res/values/styles.xml**：存储样式资源

### 4.4 启动方法

1. 在Android Studio中设置启动项目为 `WpsPasswordManagerAndroid`
2. 按Shift+F10或点击"运行"按钮启动项目
3. 首次运行时会显示登录界面，输入正确的登录信息
4. 登录成功后，插件会在通知栏中显示图标
5. 进入系统设置，授予应用辅助功能权限
6. 进入系统设置，授予应用悬浮窗权限

### 4.5 编码规范

#### 4.5.1 编码风格要求

- 使用Kotlin的标准编码风格
- 代码缩进使用4个空格
- 大括号使用新行风格
- 命名空间使用 PascalCase
- 类名使用 PascalCase
- 方法名使用 camelCase
- 变量名使用 camelCase
- 常量使用全大写加下划线

#### 4.5.2 命名规范

- 命名应具有描述性，避免使用缩写
- 类名应使用名词或名词短语
- 方法名应使用动词或动词短语
- 变量名应清晰表达其用途
- 常量名应使用全大写，单词间用下划线分隔

## 6. 常见问题解决方案

### 6.1 辅助功能权限问题

**问题描述**：应用无法获取辅助功能权限

**解决方案**：

- 在应用首次启动时，引导用户前往系统设置授予辅助功能权限
- 提供详细的权限授予步骤说明
- 在权限被拒绝时，显示友好的提示信息
- 定期检查权限状态，确保权限未被用户禁用

### 6.2 窗口监控失败

**问题描述**：无法监控WPS应用的密码窗口

**解决方案**：

- 支持多种WPS版本的窗口结构
- 使用AccessibilityService的事件监听机制
- 增加日志记录，便于调试
- 提供备用监控方法，如基于UI Automation的监控

### 6.3 密码填充失败

**问题描述**：无法自动填充密码到WPS密码输入框

**解决方案**：

- 支持多种输入框类型和结构
- 使用AccessibilityNodeInfo的performAction方法
- 增加重试机制，确保填充成功
- 提供手动填充选项作为备用方案

### 6.4 性能问题

**问题描述**：应用运行缓慢或占用资源过多

**解决方案**：

- 优化AccessibilityService的事件处理逻辑
- 减少不必要的窗口扫描
- 使用高效的算法和数据结构
- 清理不再使用的资源
- 优化后台服务的运行方式

### 6.5 兼容性问题

**问题描述**：应用在某些Android版本或WPS版本上不工作

**解决方案**：

- 支持多种Android版本的API
- 适配不同WPS版本的界面结构
- 处理不同设备的屏幕尺寸和分辨率
- 增加兼容性测试，确保在主流设备上正常工作
