### 1. 用户登录

**接口地址**: `/account/login`

**请求方式**: `POST`

**请求参数**:

| 参数名   | 类型   | 必填 | 说明     |
| -------- | ------ | ---- | -------- |
| account  | String | 是   | 用户账号 |
| password | String | 是   | 用户密码 |

**请求示例**:

```json
{
  "account": "user1",
  "password": "password123"
}
```

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": {
    "token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "account": "user1",
    "name": "张三"
  }
}
```

**响应字段说明**:

| 字段    | 类型   | 说明                                               |
| ------- | ------ | -------------------------------------------------- |
| token   | String | 访问令牌，有效期 72 小时，后续请求需在请求头中携带 |
| account | String | 用户账号                                           |
| name    | String | 用户姓名                                           |

**错误码**:

| 状态码 | 说明                                                  |
| ------ | ----------------------------------------------------- |
| 400    | 参数错误：账号和密码不能为空 / 不能使用管理员账号登录 |
| 401    | 认证失败：账号或密码错误                              |
