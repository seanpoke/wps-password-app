### 1. 用户登录

**接口地址**: `/account/login`

**请求方式**: `POST`

**请求参数**:

| 参数名      | 类型     | 必填 | 说明   |
| -------- | ------ | -- | ---- |
| account  | String | 是  | 用户账号 |
| password | String | 是  | 用户密码 |

**请求示例**:

```json
{
  "account": "user1",
  "password": "password123"
}
```

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": {
    "token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "account": "user1",
    "name": "张三"
  }
}
```

**响应字段说明**:

| 字段      | 类型     | 说明                          |
| ------- | ------ | --------------------------- |
| token   | String | 访问令牌，有效期 72 小时，后续请求需在请求头中携带 |
| account | String | 用户账号                        |
| name    | String | 用户姓名                        |

**错误码**:

| 状态码 | 说明                           |
| --- | ---------------------------- |
| 400 | 参数错误：账号和密码不能为空 / 不能使用管理员账号登录 |
| 401 | 认证失败：账号或密码错误                 |

### 2. 刷新token（心跳保活）

**接口地址**: `/account/refresh-token`

**请求方式**: `POST`

**请求头**:

| 参数名   | 类型     | 必填 | 说明      |
| :---- | :----- | :- | :------ |
| token | String | 是  | 登录返回的令牌 |

**请求参数**: 无

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": {
    "token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "account": "user1",
    "name": "张三"
  }
}
```

**响应字段说明**:

| 字段      | 类型     | 说明                   |
| :------ | :----- | :------------------- |
| token   | String | 当前使用的访问令牌（与原token相同） |
| account | String | 用户账号                 |
| name    | String | 用户姓名                 |

**业务说明**:

- 系统会从Token中获取当前登录用户信息
- TokenInterceptor会自动将token的过期时间刷新为72小时
- 前端可以定期调用此接口来保持用户登录状态，避免token过期
- 建议每隔30-60分钟调用一次此接口进行心跳保活

**错误码**:

| 状态码 | 说明              |
| :-- | :-------------- |
| 401 | 未授权：token无效或已过期 |
| 500 | token刷新失败：系统异常  |

### 3. 用户登出

**接口地址**: `/account/logout`

**请求方式**: `POST`

**请求头**:

| 参数名   | 类型     | 必填 | 说明      |
| :---- | :----- | :- | :------ |
| token | String | 是  | 登录返回的令牌 |

**请求参数**: 无

**响应示例**:

```json
{
  "message": "操作成功",
  "status": 200,
  "data": "登出成功"
}
```

**业务说明**:

- 系统会从Token中获取当前登录用户信息
- 从 Redis 中删除该 token，使 token 立即失效
- 登出后，该 token 无法再用于其他请求
- 前端应在用户点击登出按钮时调用此接口，并清除本地存储的 token

**错误码**:

| 状态码 | 说明        |
| :-- | :-------- |
| 500 | 登出失败：系统异常 |
