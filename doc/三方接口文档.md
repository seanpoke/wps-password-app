**接口地址**: `/ldap/tree`

**请求方式**: `GET`

**是否需要认证**: 否

**请求参数**: 无

**响应示例**:

```json
{
  "date": "2026-04-14 10:30:00",
  "message": "操作成功",
  "status": 200,
  "data": [
    {
      "name": "技术部",
      "fullPath": "ou=技术部,dc=example,dc=com",
      "deptList": [
        {
          "name": "开发组",
          "fullPath": "ou=开发组,ou=技术部,dc=example,dc=com",
          "deptList": [],
          "employeeList": [
            {
              "name": "张三",
              "fullPath": "uid=user1,ou=开发组,ou=技术部,dc=example,dc=com",
              "deptList": [],
              "employeeList": []
            },
            {
              "name": "李四",
              "fullPath": "uid=user2,ou=开发组,ou=技术部,dc=example,dc=com",
              "deptList": [],
              "employeeList": []
            }
          ]
        }
      ],
      "employeeList": []
    },
    {
      "name": "市场部",
      "fullPath": "ou=市场部,dc=example,dc=com",
      "deptList": [],
      "employeeList": [
        {
          "name": "王五",
          "fullPath": "uid=user3,ou=市场部,dc=example,dc=com",
          "deptList": [],
          "employeeList": []
        }
      ]
    }
  ]
}
```

**响应字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| name | String | 节点名称，部门为部门名称，员工为员工姓名 |
| fullPath | String | LDAP 完整路径，例如：`ou=技术部,dc=example,dc=com` |
| deptList | Array[LdapItem] | 子部门列表（递归结构） |
| employeeList | Array[LdapItem] | 子员工列表（叶子节点，deptList 和 employeeList 均为空数组） |
