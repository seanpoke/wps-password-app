# WPS密码管理辅助应用 - 使用指南

## 安装步骤

1. **开启未知来源安装权限**
   - 打开手机设置
   - 进入"安全"或"隐私"设置
   - 找到"未知来源应用安装"选项
   - 开启此选项，允许安装来自未知来源的应用

2. **安装APK**
   - 下载WPS密码管理辅助应用的APK文件
   - 点击APK文件开始安装
   - 按照屏幕提示完成安装过程

3. **启动应用**
   - 安装完成后，点击"打开"按钮启动应用
   - 或在应用列表中找到"WPS密码管理"应用并点击启动

## 无障碍服务启用步骤

1. **进入无障碍设置**
   - 打开手机设置
   - 进入"无障碍"设置
   - 找到"已下载的服务"或"服务"选项

2. **启用WPS密码管理服务**
   - 在服务列表中找到"WPS密码管理服务"
   - 点击进入服务详情
   - 开启"使用WPS密码管理服务"开关
   - 点击"确定"确认启用

3. **验证服务状态**
   - 返回应用主界面
   - 查看"无障碍服务"按钮状态
   - 如果显示"无障碍服务已启用"，则表示服务已成功启用

## 功能使用说明

### 生成密码

1. **打开WPS应用**
   - 启动WPS Office应用
   - 打开或创建一个文档

2. **加密文档**
   - 在文档编辑界面，点击"文件"菜单
   - 选择"另存为"
   - 勾选"设置密码"选项
   - 点击"确定"

3. **生成并填充密码**
   - WPS会弹出密码输入对话框
   - 切换到WPS密码管理应用
   - 点击"生成密码"按钮
   - 应用会生成一个12位随机密码并显示
   - 密码会自动填充到WPS的密码输入对话框
   - 点击WPS对话框中的"确定"按钮完成加密

### 自动填充密码

1. **打开加密文档**
   - 在WPS中打开一个加密的文档
   - WPS会弹出密码输入对话框

2. **自动填充**
   - 无障碍服务会自动检测到密码输入对话框
   - 如果应用中存储了该文档的密码，会自动填充
   - 如果未存储密码，需要手动输入

### 管理密码

1. **查看存储的密码**
   - 打开WPS密码管理应用
   - 点击"管理密码"按钮
   - 查看已存储的密码列表

2. **删除密码**
   - 在密码列表中，找到要删除的密码
   - 点击删除按钮
   - 确认删除操作

## 与ES文件浏览器配合使用

1. **打开ES文件浏览器**
   - 启动ES文件浏览器应用
   - 导航到包含加密WPS文档的文件夹

2. **查看文件备注**
   - 长按加密文档
   - 选择"属性"选项
   - 在属性对话框中查看"备注"字段
   - 如果之前已将密码写入备注，这里会显示密码

3. **写入密码到文件备注**
   - 在WPS密码管理应用中生成密码
   - 点击"管理密码"按钮
   - 选择要写入备注的密码
   - 点击"写入到文件备注"按钮
   - 选择对应的文件
   - 应用会将密码写入文件的备注信息

## 常见问题解决

1. **无障碍服务未启用**
   - 检查手机设置中的无障碍服务是否已启用
   - 确保应用已获得必要的权限
   - 尝试重启手机后重新启用服务

2. **密码填充失败**
   - 确保WPS应用是最新版本
   - 检查无障碍服务是否正常运行
   - 尝试手动输入密码

3. **密码存储失败**
   - 检查手机存储空间是否充足
   - 确保应用已获得存储权限
   - 尝试清除应用缓存后重新存储

4. **与ES文件浏览器不兼容**
   - 确保ES文件浏览器版本为v4.4.2.9.8
   - 检查文件权限是否正确
   - 尝试使用其他文件浏览器

## 安全注意事项

1. **密码安全**
   - 不要将密码告诉他人
   - 定期更改重要文档的密码
   - 不要在公共场合使用密码填充功能

2. **应用安全**
   - 确保应用是从可信来源下载
   - 定期更新应用到最新版本
   - 不要Root手机，以免影响安全存储

3. **数据安全**
   - 定期备份存储的密码
   - 不要在不安全的网络环境下使用应用
   - 确保手机有屏幕锁定保护

## 功能演示

### 场景1：加密文档并生成密码

1. 打开WPS Office应用
2. 创建一个新文档
3. 点击"文件" -> "另存为"
4. 勾选"设置密码"选项
5. 切换到WPS密码管理应用
6. 点击"生成密码"按钮
7. 密码会自动填充到WPS的密码输入对话框
8. 点击"确定"完成加密

### 场景2：打开加密文档并自动填充密码

1. 打开WPS Office应用
2. 选择一个加密的文档
3. WPS会弹出密码输入对话框
4. 无障碍服务会自动检测并填充密码
5. 文档会自动打开

### 场景3：使用ES文件浏览器查看密码

1. 打开ES文件浏览器
2. 导航到包含加密文档的文件夹
3. 长按加密文档
4. 选择"属性"
5. 在备注字段中查看密码
