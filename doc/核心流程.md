### **1. 添加依赖**

在 app 模块的 `build.gradle` 中添加 Apache POI 的依赖（主要需要 `poi` 和 `poi-ooxml`，但读取 OLE 结构只需要 `poi` 核心库）：

```
dependencies {
    // 使用最新版本，建议使用 5.2.x 或更高版本
    implementation 'org.apache.poi:poi:5.2.3'
    // 如果还需要处理docx等，可能需要 poi-ooxml，但读取 EncryptionInfo 仅需核心库
}

```

> **注意：** Apache POI 库体积较大，如果对包体积极其敏感，可以考虑使用精简版的 OLE 解析库（如 [jdereader](https://github.com/leonbloy/jdereader)）或者自行根据 CFB 规范解析文件头（实现难度大）。

### **2. 编写读取工具类**

以下是一个 Kotlin 工具类，演示如何读取 `EncryptionInfo` 流并计算哈希值，用于判断密码是否修改。

```
import org.apache.poi.poifs.filesystem.POIFSFileSystem
import java.io.FileInputStream
import java.io.File
import java.security.MessageDigest

object OfficeEncryptUtils {

    /**
     * 获取加密文件的 EncryptionInfo 流的哈希值
     * @param file 文件对象
     * @return 哈希字符串（SHA-256），如果文件未加密或读取失败返回 null
     */
    fun getEncryptionInfoHash(file: File): String? {
        try {
            // 1. 打开文件流
            val fis = FileInputStream(file)
            
            // 2. 使用 POI 创建 OLE 文件系统对象
            // 注意：这不需要密码即可打开容器外壳
            val fs = POIFSFileSystem(fis)

            // 3. 检查是否存在 EncryptionInfo 流
            // OLE 结构内部像文件系统一样，有目录和文件的概念
            if (!fs.root.hasEntry("EncryptionInfo")) {
                fs.close()
                fis.close()
                return null // 文件未加密，或者是旧版加密格式
            }

            // 4. 读取 EncryptionInfo 流
            val entry = fs.root.getEntry("EncryptionInfo")
            val inputStream = fs.createDocumentInputStream(entry)
            
            // 读取所有字节
            val buffer = inputStream.readBytes()
            
            inputStream.close()
            fs.close()
            fis.close()

            // 5. 计算哈希值
            val md = MessageDigest.getInstance("SHA-256")
            val hashBytes = md.digest(buffer)
            
            // 转换为十六进制字符串
            return hashBytes.joinToString("") { "%02x".format(it) }

        } catch (e: Exception) {
            e.printStackTrace()
            // 可能不是 OLE 文件，或者文件损坏
            return null
        }
    }
}
```
