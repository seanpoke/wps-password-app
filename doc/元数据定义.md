出现“无法打开文件目录，请安装文件管理器”这个提示，根本原因是**你的 App 抛出了 `ActivityNotFoundException`**。

在安卓 11 (API 30) 及以上版本中，谷歌引入了**[包可见性](https://developer.android.com/training/package-visibility)**限制。**即使手机上明明安装了文件管理器，如果你的代码没有在清单文件中“声明”你要找它，系统也会假装看不见它，从而报错说找不到。**

要彻底解决这个问题，需要两步调整：

### **第一步：在 AndroidManifest.xml 中添加 `<queries>` 标签（最关键）**

你必须在 `AndroidManifest.xml` 的 `<application>` 标签**外部**（与之平级），声明你要查询哪些文件管理器。否则后面的代码全都会失效。

```
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.your.package">

    <!-- 你的其他权限... -->

    <!-- 必须加上这个 queries 节点，解决 Android 11+ 看不见文件管理器的问题 -->
    <queries>
        <!-- 三星 -->
        <package android:name="com.sec.android.app.myfiles" />
        <!-- 华为 -->
        <package android:name="com.huawei.hidisk" />
        <!-- 小米 -->
        <package android:name="com.mi.android.globalFileexplorer" />
        <!-- OPPO -->
        <package android:name="com.coloros.filemanager" />
        <!-- vivo -->
        <package android:name="com.vivo.filemanager" />
        <!-- 原生 Android (Pixel 等) -->
        <package android:name="com.google.android.apps.nbu.files" />
        
        <!-- 通用的 Intent 匹配：声明你想处理 "查看文件夹" 这个动作的应用 -->
        <intent>
            <action android:name="android.intent.action.VIEW" />
            <data android:mimeType="resource/folder" />
        </intent>
    </queries>

    <application
        android:name=".YourApplication"
        ... >
        <!-- 你的 Activity 等组件 -->
    </application>

</manifest>

```

### **第二步：使用带“降级策略”的增强版代码**

加了 `<queries>` 之后，我们需要写一段更加健壮的代码：先尝试精准跳转指定目录，如果精准跳转失败，再尝试通用协议，并且要**捕获异常**，避免 App 崩溃。

你可以直接使用下面这个封装好的工具类方法：

```
import android.content.Context
import android.content.Intent
import android.content.pm.PackageManager
import android.net.Uri
import android.os.Environment
import android.provider.Settings
import android.widget.Toast
import java.io.File

object FileManagerUtil {

    /**
     * 安全地打开指定文件夹
     */
    fun openFolder(context: Context, targetFolderPath: String) {
        // 1. 校验路径是否存在且是文件夹
        val folder = File(targetFolderPath)
        if (!folder.exists() || !folder.isDirectory) {
            Toast.makeText(context, "目标目录不存在或不是文件夹", Toast.LENGTH_SHORT).show()
            return
        }

        // 2. 尝试精准跳转各大厂商文件管理器
        if (tryOpenSpecificFileManager(context, targetFolderPath)) {
            return
        }

        // 3. 如果精准跳转没匹配到，尝试通用隐式 Intent (MIME: resource/folder)
        if (tryOpenGenericFileManager(context, targetFolderPath, "resource/folder")) {
            return
        }

        // 4. 终极兜底：使用通配符 MIME (部分极简系统只认这个)
        if (tryOpenGenericFileManager(context, targetFolderPath, "*/*")) {
            return
        }

        // 5. 如果全部失败，提示用户
        Toast.makeText(context, "您的设备上没有可用的文件管理器", Toast.LENGTH_LONG).show()
    }

    /**
     * 尝试通过包名精准打开
     */
    private fun tryOpenSpecificFileManager(context: Context, folderPath: String): Boolean {
        val packageInfoList = listOf(
            "com.sec.android.app.myfiles",      // 三星
            "com.huawei.hidisk",                 // 华为
            "com.mi.android.globalFileexplorer", // 小米
            "com.coloros.filemanager",           // OPPO/一加
            "com.vivo.filemanager",              // vivo
            "com.google.android.apps.nbu.files"  // 原生
        )

        for (packageName in packageInfoList) {
            if (isPackageInstalled(context, packageName)) {
                try {
                    val intent = Intent(Intent.ACTION_VIEW)
                    intent.setPackage(packageName)
                    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
                    intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)

                    // 针对不同厂商塞入不同的路径参数
                    when (packageName) {
                        "com.sec.android.app.myfiles" -> {
                            intent.putExtra("com.sec.android.app.myfiles.PATH", folderPath)
                            intent.putExtra("start_path", folderPath)
                        }
                        "com.huawei.hidisk" -> {
                            intent.putExtra("absolutePath", folderPath)
                            intent.putExtra("path", folderPath)
                        }
                        "com.mi.android.globalFileexplorer" -> {
                            intent.putExtra("explorer_path", folderPath)
                        }
                        "com.coloros.filemanager" -> {
                            intent.putExtra("absolute_path", folderPath)
                        }
                    }
                    
                    context.startActivity(intent)
                    return true // 成功启动，返回 true
                } catch (e: Exception) {
                    // 该包名虽然存在，但可能启动失败（极其少见），捕获异常继续尝试下一个
                    e.printStackTrace()
                }
            }
        }
        return false
    }

    /**
     * 尝试通用隐式打开
     */
    private fun tryOpenGenericFileManager(context: Context, folderPath: String, mimeType: String): Boolean {
        return try {
            val uri = Uri.parse("file://$folderPath")
            val intent = Intent(Intent.ACTION_VIEW)
            intent.setDataAndType(uri, mimeType)
            intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
            intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
            
            context.startActivity(intent)
            true
        } catch (e: Exception) {
            // 捕获 ActivityNotFoundException，说明还是没有应用能处理
            false
        }
    }

    /**
     * 判断某包名是否安装
     */
    private fun isPackageInstalled(context: Context, packageName: String): Boolean {
        return try {
            context.packageManager.getPackageInfo(packageName, 0)
            true
        } catch (e: PackageManager.NameNotFoundException) {
            false
        }
    }
}

```

### **使用方法：**

在你的按钮点击事件中直接调用：

```
// 例如你想跳转到外部存储的 Download 目录
val path = Environment.getExternalStorageDirectory().toString() + "/Download"

// 或者你自己的私有目录
// val path = getExternalFilesDir(null).toString() + "/myFolder"

FileManagerUtil.openFolder(this, path)

```

### **补充排查点（如果按上面做了还不行）：**

1. **确认你传入的路径是否带有 `file://` 前缀**：在 `tryOpenGenericFileManager` 方法中我已经帮你拼接了 `"file://" + folderPath`，你传入的 `folderPath` 只需要是纯物理路径即可，例如 `/storage/emulated/0/Download`。
2. **沙盒目录问题**：如果你的 `targetFolderPath` 是位于 App 的沙盒内部（如 `/Android/data/你的包名/`），**很多文件管理器是直接拒绝打开或无权限显示的**，这是安卓的安全机制。建议测试时先用 `/sdcard/Download` 这种公共目录测试是否能成功唤起。
