# ECC 加密算法技术规范

## 1. 算法概述

本项目采用 **ECIES** (Elliptic Curve Integrated Encryption Scheme) 椭圆曲线混合加密方案，结合 ECC 非对称加密和 AES 对称加密的优势，实现安全高效的密码加密传输。

### 1.1 技术选型

| 组件 | 算法/参数 | 说明 |
|------|----------|------|
| 椭圆曲线 | secp256r1 (NIST P-256) | 256位安全强度 |
| 密钥协商 | ECDH | 椭圆曲线 Diffie-Hellman |
| 对称加密 | AES-256-CBC | 高级加密标准 |
| 填充模式 | PKCS5Padding | 分组密码填充 |
| 密钥派生 | SHA-256 | 哈希函数派生AES密钥 |
| IV长度 | 16字节 | AES块大小 |

### 1.2 优势对比

- **密文更短**: 相比 RSA-2048 (约344字符)，ECC 密文长度更短
- **安全性更高**: 256位 ECC 安全性相当于 3072位 RSA
- **性能更优**: 加解密速度更快，适合移动端和物联网设备

## 2. 加密流程详解

### 2.1 整体流程图

```
┌─────────────┐
│  明文数据    │
└──────┬──────┘
       │
       ▼
┌─────────────────────────────────┐
│ 1. 解析服务器公钥 (Base64解码)   │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 2. 生成临时 ECC 密钥对           │
│    (Ephemeral KeyPair)          │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 3. ECDH 密钥协商                 │
│    临时私钥 + 服务器公钥         │
│    → 共享密钥 (Shared Secret)   │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 4. 密钥派生                      │
│    SHA-256(共享密钥)             │
│    → AES-256 密钥               │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 5. 生成随机 IV (16字节)          │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 6. AES-CBC 加密                  │
│    明文 + AES密钥 + IV           │
│    → 密文                       │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 7. 数据组合                      │
│ [公钥长度][临时公钥][IV][密文]   │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 8. Base64 编码                   │
│    → 最终加密字符串              │
└─────────────────────────────────┘
```

### 2.2 详细步骤说明

#### 步骤 1: 解析服务器公钥

```java
// 输入: Base64 编码的服务器公钥字符串
byte[] publicKeyBytes = Base64.getDecoder().decode(publicKeyStr);
KeyFactory keyFactory = KeyFactory.getInstance("EC", "BC");
PublicKey publicKey = keyFactory.generatePublic(
    new X509EncodedKeySpec(publicKeyBytes)
);
```

**关键点**:
- 使用 X509EncodedKeySpec 解析公钥
- 公钥格式为 DER 编码的 X.509 SubjectPublicKeyInfo

#### 步骤 2: 生成临时密钥对

```java
ECGenParameterSpec ecSpec = new ECGenParameterSpec("secp256r1");
KeyPairGenerator keyPairGenerator = KeyPairGenerator.getInstance("EC", "BC");
keyPairGenerator.initialize(ecSpec, new SecureRandom());
KeyPair tempKeyPair = keyPairGenerator.generateKeyPair();
```

**关键点**:
- 每次加密都生成新的临时密钥对（保证前向安全性）
- 使用 SecureRandom 确保随机性
- 曲线名称必须为 `secp256r1`

#### 步骤 3: ECDH 密钥协商

```java
KeyAgreement keyAgreement = KeyAgreement.getInstance("ECDH", "BC");
keyAgreement.init(tempKeyPair.getPrivate());
keyAgreement.doPhase(publicKey, true);
byte[] sharedSecret = keyAgreement.generateSecret();
```

**关键点**:
- 使用临时私钥和服务器公钥进行密钥协商
- 生成的共享密钥长度取决于曲线参数（secp256r1 约 32 字节）

#### 步骤 4: 密钥派生

```java
MessageDigest sha256 = MessageDigest.getInstance("SHA-256");
byte[] aesKeyBytes = sha256.digest(sharedSecret);
```

**关键点**:
- 对共享密钥进行 SHA-256 哈希
- 输出固定 32 字节（256位），作为 AES-256 密钥

#### 步骤 5: 生成随机 IV

```java
SecureRandom random = new SecureRandom();
byte[] iv = new byte[16];
random.nextBytes(iv);
```

**关键点**:
- IV 长度必须为 16 字节（AES 块大小）
- 每次加密必须使用不同的随机 IV
- IV 不需要保密，但必须不可预测

#### 步骤 6: AES-CBC 加密

```java
Cipher aesCipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
SecretKeySpec aesKeySpec = new SecretKeySpec(aesKeyBytes, "AES");
IvParameterSpec ivSpec = new IvParameterSpec(iv);
aesCipher.init(Cipher.ENCRYPT_MODE, aesKeySpec, ivSpec);
byte[] encryptedData = aesCipher.doFinal(data.getBytes("UTF-8"));
```

**关键点**:
- 明文必须先转换为 UTF-8 字节数组
- 使用 CBC 模式和 PKCS5Padding 填充
- AES 密钥长度为 256 位（32 字节）

#### 步骤 7: 数据组合

```java
byte[] tempPublicKeyBytes = tempKeyPair.getPublic().getEncoded();

// 格式：[临时公钥长度(4字节)][临时公钥][IV(16字节)][密文]
byte[] result = new byte[4 + tempPublicKeyBytes.length + iv.length + encryptedData.length];

// 写入临时公钥长度（大端序）
result[0] = (byte) ((tempPublicKeyBytes.length >> 24) & 0xFF);
result[1] = (byte) ((tempPublicKeyBytes.length >> 16) & 0xFF);
result[2] = (byte) ((tempPublicKeyBytes.length >> 8) & 0xFF);
result[3] = (byte) (tempPublicKeyBytes.length & 0xFF);

// 写入临时公钥
System.arraycopy(tempPublicKeyBytes, 0, result, 4, tempPublicKeyBytes.length);

// 写入 IV
System.arraycopy(iv, 0, result, 4 + tempPublicKeyBytes.length, iv.length);

// 写入密文
System.arraycopy(encryptedData, 0, result, 4 + tempPublicKeyBytes.length + iv.length, encryptedData.length);
```

**二进制结构**:

```
偏移量      长度          内容
─────────────────────────────────────
0-3         4字节         临时公钥长度（Big-Endian）
4-N         N字节         临时公钥（X509编码）
N+1-N+16    16字节        IV（初始化向量）
N+17-End    变长          AES密文（PKCS5填充）
```

#### 步骤 8: Base64 编码

```java
String encryptedDataBase64 = Base64.getEncoder().encodeToString(result);
```

**关键点**:
- 使用标准 Base64 编码（不使用 URL Safe 版本）
- 不包含换行符

## 3. 解密流程详解

### 3.1 整体流程图

```
┌─────────────────┐
│ Base64加密字符串 │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 1. Base64 解码                   │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 2. 解析数据结构                   │
│ - 提取临时公钥长度（4字节）       │
│ - 提取临时公钥                    │
│ - 提取 IV (16字节)               │
│ - 提取密文                       │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 3. 解析服务器私钥                 │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 4. 解析临时公钥                   │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 5. ECDH 密钥协商                  │
│    服务器私钥 + 临时公钥          │
│    → 共享密钥                    │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 6. 密钥派生                      │
│    SHA-256(共享密钥)             │
│    → AES-256 密钥               │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 7. AES-CBC 解密                  │
│    密文 + AES密钥 + IV           │
│    → 明文字节数组                │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ 8. UTF-8 解码                    │
│    → 原始明文字符串              │
└─────────────────────────────────┘
```

### 3.2 关键代码实现

```java
// 1. Base64 解码
byte[] encryptedData = Base64.getDecoder().decode(encryptedDataBase64);

// 2. 解析临时公钥长度（大端序）
int publicKeyLength = ((encryptedData[0] & 0xFF) << 24) |
                      ((encryptedData[1] & 0xFF) << 16) |
                      ((encryptedData[2] & 0xFF) << 8) |
                      (encryptedData[3] & 0xFF);

// 3. 提取各部分数据
byte[] tempPublicKeyBytes = new byte[publicKeyLength];
System.arraycopy(encryptedData, 4, tempPublicKeyBytes, 0, publicKeyLength);

byte[] iv = new byte[16];
System.arraycopy(encryptedData, 4 + publicKeyLength, iv, 0, iv.length);

byte[] ciphertext = new byte[encryptedData.length - 4 - publicKeyLength - iv.length];
System.arraycopy(encryptedData, 4 + publicKeyLength + iv.length, ciphertext, 0, ciphertext.length);

// 4. 解析私钥
byte[] privateKeyBytes = Base64.getDecoder().decode(privateKeyStr);
KeyFactory keyFactory = KeyFactory.getInstance("EC", "BC");
PrivateKey privateKey = keyFactory.generatePrivate(
    new PKCS8EncodedKeySpec(privateKeyBytes)
);

// 5. 解析临时公钥
PublicKey tempPublicKey = keyFactory.generatePublic(
    new X509EncodedKeySpec(tempPublicKeyBytes)
);

// 6. ECDH 密钥协商
KeyAgreement keyAgreement = KeyAgreement.getInstance("ECDH", "BC");
keyAgreement.init(privateKey);
keyAgreement.doPhase(tempPublicKey, true);
byte[] sharedSecret = keyAgreement.generateSecret();

// 7. 密钥派生
MessageDigest sha256 = MessageDigest.getInstance("SHA-256");
byte[] aesKeyBytes = sha256.digest(sharedSecret);

// 8. AES 解密
Cipher aesCipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
SecretKeySpec aesKeySpec = new SecretKeySpec(aesKeyBytes, "AES");
IvParameterSpec ivSpec = new IvParameterSpec(iv);
aesCipher.init(Cipher.DECRYPT_MODE, aesKeySpec, ivSpec);
byte[] decryptedBytes = aesCipher.doFinal(ciphertext);

// 9. UTF-8 解码
String originalData = new String(decryptedBytes, "UTF-8");
```

### 4.2 Kotlin 实现示例

```kotlin
import org.bouncycastle.jce.provider.BouncyCastleProvider
import java.security.*
import javax.crypto.Cipher
import javax.crypto.KeyAgreement
import javax.crypto.spec.IvParameterSpec
import javax.crypto.spec.SecretKeySpec
import java.security.spec.X509EncodedKeySpec
import java.nio.ByteBuffer
import java.util.Base64

object EccEncryptor {
    
    private const val ALGORITHM = "EC"
    private const val CURVE_NAME = "secp256r1"
    private const val PROVIDER = "BC"
    private const val AES_ALGORITHM = "AES/CBC/PKCS5Padding"
    
    init {
        Security.addProvider(BouncyCastleProvider())
    }
    
    /**
     * 使用服务器公钥加密密码
     * @param password 原始密码字符串
     * @param serverPublicKeyBase64 Base64编码的服务器公钥
     * @return Base64编码的加密数据
     */
    fun encryptPassword(password: String, serverPublicKeyBase64: String): String {
        try {
            // 1. 解析服务器公钥
            val publicKeyBytes = Base64.getDecoder().decode(serverPublicKeyBase64)
            val keyFactory = KeyFactory.getInstance(ALGORITHM, PROVIDER)
            val publicKey = keyFactory.generatePublic(X509EncodedKeySpec(publicKeyBytes))
            
            // 2. 生成临时密钥对
            val ecSpec = java.security.spec.ECGenParameterSpec(CURVE_NAME)
            val keyPairGenerator = KeyPairGenerator.getInstance(ALGORITHM, PROVIDER)
            keyPairGenerator.initialize(ecSpec, SecureRandom())
            val tempKeyPair = keyPairGenerator.generateKeyPair()
            
            // 3. ECDH 密钥协商
            val keyAgreement = KeyAgreement.getInstance("ECDH", PROVIDER)
            keyAgreement.init(tempKeyPair.private)
            keyAgreement.doPhase(publicKey, true)
            val sharedSecret = keyAgreement.generateSecret()
            
            // 4. 密钥派生 (SHA-256)
            val sha256 = MessageDigest.getInstance("SHA-256")
            val aesKeyBytes = sha256.digest(sharedSecret)
            
            // 5. 生成随机 IV
            val iv = ByteArray(16)
            SecureRandom().nextBytes(iv)
            
            // 6. AES-CBC 加密
            val aesCipher = Cipher.getInstance(AES_ALGORITHM)
            val aesKeySpec = SecretKeySpec(aesKeyBytes, "AES")
            val ivSpec = IvParameterSpec(iv)
            aesCipher.init(Cipher.ENCRYPT_MODE, aesKeySpec, ivSpec)
            val ciphertext = aesCipher.doFinal(password.toByteArray(Charsets.UTF_8))
            
            // 7. 组合数据
            val tempPubKeyBytes = tempKeyPair.public.encoded
            val buffer = ByteBuffer.allocate(4 + tempPubKeyBytes.size + iv.size + ciphertext.size)
            buffer.putInt(tempPubKeyBytes.size)  // 大端序
            buffer.put(tempPubKeyBytes)
            buffer.put(iv)
            buffer.put(ciphertext)
            
            // 8. Base64 编码
            return Base64.getEncoder().encodeToString(buffer.array())
            
        } catch (e: Exception) {
            throw RuntimeException("ECC加密失败: ${e.message}", e)
        }
    }
}
```

## 5. 关键技术要点

### 5.1 必须保持一致的参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 椭圆曲线 | `secp256r1` | Android 中可能叫 `prime256v1` |
| 公钥编码 | X509EncodedKeySpec | DER 编码格式 |
| 私钥编码 | PKCS8EncodedKeySpec | DER 编码格式 |
| AES 模式 | CBC | 密码块链模式 |
| AES 填充 | PKCS5Padding | 等同于 PKCS7Padding |
| 密钥派生 | SHA-256 | 哈希函数 |
| IV 长度 | 16 字节 | AES 块大小 |
| 字节序 | Big-Endian | 公钥长度字段 |
| 字符编码 | UTF-8 | 明文转字节 |

### 5.2 安全注意事项

⚠️ **重要安全实践**:

1. **临时密钥对**: 每次加密必须生成新的临时密钥对，确保前向安全性
2. **随机 IV**: 每次加密必须使用新的随机 IV，禁止重用
3. **SecureRandom**: 所有随机数生成必须使用 `SecureRandom`，不要使用 `Random`
4. **密钥保护**: 服务器私钥必须妥善保管，不得泄露
5. **传输安全**: 建议配合 HTTPS 使用，提供双层保护
6. **错误处理**: 解密失败时不要返回详细错误信息，防止侧信道攻击

### 5.3 常见错误及解决方案

| 错误类型 | 原因 | 解决方案 |
|---------|------|---------|
| `InvalidKeyException` | 密钥格式错误或曲线不匹配 | 检查公钥是否为 X509 格式，确认曲线为 secp256r1 |
| `BadPaddingException` | 解密失败，密钥不匹配 | 检查密钥是否正确，数据是否被篡改 |
| `NoSuchAlgorithmException` | 算法不支持 | 确认已注册 BouncyCastle Provider |
| `NoSuchProviderException` | Provider 未注册 | 在静态块中调用 `Security.addProvider(new BouncyCastleProvider())` |
| 解密结果乱码 | 字符编码不一致 | 确保加密和解密都使用 UTF-8 编码 |
| 公钥长度异常 | 字节序错误 | 确认使用大端序（Big-Endian）读取公钥长度 |

## 7. 性能优化建议

### 7.1 公钥缓存

```kotlin
object PublicKeyCache {
    private var cachedPublicKey: String? = null
    private var cacheTimestamp: Long = 0
    private const val CACHE_VALID_DURATION = 24 * 60 * 60 * 1000L // 24小时
    
    fun getPublicKey(): String {
        val now = System.currentTimeMillis()
        if (cachedPublicKey != null && (now - cacheTimestamp) < CACHE_VALID_DURATION) {
            return cachedPublicKey!!
        }
        
        // 从服务器获取新公钥
        val newPublicKey = fetchPublicKeyFromServer()
        cachedPublicKey = newPublicKey
        cacheTimestamp = now
        return newPublicKey
    }
}
```

### 7.2 异步加密
